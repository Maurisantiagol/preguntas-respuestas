# preguntas-respuestas

Material de preguntas y respuestas para la exposición del proyecto **Tilin's Kitchen**, un restaurante italiano con asistente virtual (IPN, ESCOM, Tecnologías del Lenguaje Natural).

La página presenta 15 preguntas críticas en 5 categorías, cada una con su respuesta sugerida, sobre el proyecto: el clasificador de intenciones (SVM), la recomendación por similitud coseno (umbral 0.05), la reducción del catálogo de 62,126 a 3,783 recetas, la API en Flask y el F1 de 0.94.

> No es la aplicación del restaurante: es solo el material de apoyo para su exposición.

## Qué contiene

- Un solo archivo: `index.html`.
- React 18 y Babel por CDN, sin compilación ni dependencias que instalar.

## Cómo verlo

Abre `index.html` en el navegador (doble clic) o sírvelo con cualquier servidor estático:

```bash
python -m http.server
```

Luego abre http://localhost:8000 en el navegador.
